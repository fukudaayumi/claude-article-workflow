# 記事本文作成スキル

骨子ファイル（`{記事No}_outline.md`）を読み込み、SEOコンテンツフレームに完全準拠した記事本文を `{記事No}_index.md` として出力する。

---

## ステップ1：入力情報の収集

以下の情報をユーザーに確認する。

1. **記事No**：管理番号（例：151）

---

## ステップ2：骨子ファイルを読み込む

読み込みパス：`./articles/{記事No}/{記事No}_outline.md`

取得すべき情報：
- タイトル（H1）
- 導入文（300〜400文字）
- Hタグ設計（H2・H3の文言と順序）
- 各セクションへの補足指示（骨子内のコメント）

---

## ステップ3：記事本文を生成する

### Hタグ遵守ルール（絶対厳守）

- H1・H2・H3の文言は骨子と**一字一句完全一致**
- H2/H3の構成順序も骨子通りに維持
- 骨子にない見出しの追加・削除・言い換えは**禁止**

### トーン・文量

- トーン：**フォーマル・ビジネス寄り**
- 文字数目安：**3,000〜5,000文字**

### 各セクションの方針

- **「はじめに」**：骨子の導入文をそのまま使う。独自の説明や補足を追加しない（H3は置かない）
- **コンテンツH2**：各H3に対して、コードブロック・表・箇条書きを適宜使い視認性を高める
- **「まとめ」**：箇条書きは使わず、3〜5文の文章で記事の要点をまとめる。末尾にサービスサイトを紹介する文章（2〜3行）を加える

---

## ステップ4：Markdownフォーマットルールを適用する

### テキスト装飾

- 太字：`**テキスト**`
- リンク：`[テキスト](URL)`

### リスト

- 箇条書き：`- 項目`
- 番号付きリスト：
  ```
  1.項目</br>
  2.項目</br>
  3.項目
  ```
- ネスト：2スペースで表現

### テーブル

**ヘッダ行がある場合（`<div class="addHead">`で囲む）**：

```
<div class="addHead">

| 項目       | 内容                 |
| ---------- | -------------------- |
| 値1        | 説明1                |

</div>
```

**ヘッダ行が不要な場合**：divタグなしでそのまま記述

### クリーニングルール

- 「ポイント：」「実務のイメージ：」などの装飾ラベルは削除してテキストに統合する
- 本文中の `---`（区切り線）は**すべて削除する**
- H1タイトルはフロントマターに記載するため、本文中には書かない

---

## ステップ5：frontmatterを付与する

ファイル冒頭に以下を記述する。

```
---
layout: "@/layouts/BlogDetailLayout/index.astro"
title: {骨子のtitleをそのまま記載}
author:
description: {記事内容から100〜120文字のmeta description を生成}
pubDate: {今日の日付 例: 2026-03-03}
category: {下記から1つ選択}
---
```

### categoryの選択肢

`.claude/categories.md` を読み込み、カテゴリ一覧を参照する。

---

## ステップ6：ファイルを出力する

出力パス：`./articles/{記事No}/{記事No}_index.md`

ファイル構成：
1. frontmatter（`---` ブロック）
2. `## はじめに` から始まる本文（H1タイトルは書かない）

---

## 完了時の報告

出力完了後、以下を報告する：

```
✅ 記事本文を出力しました

- ファイル：articles/{記事No}/{記事No}_index.md
- タイトル：{title}
- カテゴリ：{category}
- H2構成：はじめに / {H2一覧} / まとめ
```
