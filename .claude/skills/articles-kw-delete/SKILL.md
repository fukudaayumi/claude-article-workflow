# キーワード削除・No再採番スキル

`keywords/all_keywords.md` から指定した記事NoのキーワードをすべてE除し、残ったエントリのNoを連番に詰め直す。

---

## ステップ1：削除対象Noを確認する

削除する記事Noをユーザーに確認する（複数指定可）。

- 例：「3」「5, 8」「12〜15」など、複数・範囲指定を受け付ける
- Noが存在しない場合はエラーを出して終了する

```
❌ エラー：指定されたNo {N} は all_keywords.md に存在しません。
```

---

## ステップ2：all_keywords.md の内容を読み込む

`Read` ツールで `keywords/all_keywords.md` 全体を読み込む。

---

## ステップ3：削除対象行を特定する

指定されたNoに一致する行（★行・サブKW行ともに）をすべて削除対象としてマークする。

- 判定基準：タブ区切りの2列目（記事No列）の値が一致する行
- ★行・サブKW行の区別なく、同じNoの行はすべて削除する

---

## ステップ4：行を削除し、Noを再採番する

1. 削除対象行を除いた残りの行を抽出する
2. ★行に振られている記事Noを昇順に並べ、1から連番で振り直す
3. 同じ元のNoを持つサブKW行も、対応する新しいNoに更新する

### 再採番の例

```
削除前：No 1, 2, 3, 5, 6（No 4を削除済み）
再採番後：No 1, 2, 3, 4, 5
```

---

## ステップ5：all_keywords.md に書き戻す

`Edit` ツールでヘッダー行以降のデータ部分を書き換える（ヘッダーとメタ情報は保持する）。

---

## 完了時の報告

```
✅ キーワード削除・再採番が完了しました

- 削除したNo：{削除No一覧}
- 削除件数：{N}件（メインKW {N}件 / サブKW {N}件）
- 再採番後の最終No：{最終No}
- 更新ファイル：keywords/all_keywords.md
```
