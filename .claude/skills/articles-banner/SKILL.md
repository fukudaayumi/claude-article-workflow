# バナー自動生成スキル

記事本文を読み込んでバナーの構成・内容を決定し、記事中バナーの画像パスをMarkdownに挿入した上でローカルサーバーを起動する。
ユーザーはFigmaプラグインを開くだけでバナーが自動作成される。

---

## ステップ1：入力情報の収集

以下の情報をユーザーに確認する。

1. **記事No**：管理番号（例：131）

---

## ステップ2：記事本文を読み込む

読み込みパス：`./articles/{記事No}/{記事No}_index_revised.md`

ファイルが存在しない場合は `{記事No}_index.md` を読む。

---

## ステップ3：バナー構成を決定する

### 枚数ルール

- **タイトルバナー**：1枚必須
- **記事中バナー**：1〜3枚

### テンプレート選択ルール

記事中バナーが2枚以上の場合、**全て同じテンプレートを使うことは禁止**。

| テンプレート名 | 使う内容 |
|------|------|
| ポジティブ（緑） | メリット・できること・おすすめポイントなどポジティブな内容 |
| ネガティブ（赤） | デメリット・注意点・失敗しやすいポイントなどネガティブな内容 |
| その他 | 特徴・要点まとめ・比較・手順など上記に当てはまらない内容 |

### 箇条書き項目数ルール

- 1バナーあたりの項目数は **2〜4個**

### 内容選定の方針

- 記事中から「箇条書きになっている・なりうる」セクションを探す
- 読者にとって視覚的にまとめると価値が高い箇所を優先する
- 項目テキストはバナーに収まる **短い表現（15〜25文字目安）** に圧縮する
- リストタイトルも **簡潔に（10〜15文字目安）** まとめる

---

## ステップ4：JSONを構築する

以下のフォーマットでJSONを組み立てる。

```json
{
  "articleNo": "{記事No}",
  "banners": [
    {
      "type": "タイトルバナー",
      "frameName": "thumbnail",
      "title": "{記事タイトル（title フィールドをそのまま使用）}"
    },
    {
      "type": "{ポジティブ or ネガティブ or その他}",
      "frameName": "{listTitleを英語スネークケースに変換した値}",
      "listTitle": "{リストタイトル}",
      "insertBefore": "{画像を挿入する直前の見出しテキスト（## または ### の行全体）}",
      "items": ["{項目1}", "{項目2}", "{項目3}"]
    }
  ]
}
```

### frameName の決め方

| バナー種別 | frameName |
|------|------|
| タイトルバナー | `thumbnail` |
| 記事中バナー | リストタイトルを英語に翻訳してスネークケースに変換 |

**スネークケース変換ルール：**
- 日本語のlistTitleを英語に意訳する（直訳ではなく自然な英語で）
- すべて小文字にする
- 単語間はアンダースコア `_` で区切る
- 例：「OSを理解するメリット」→ `os_learning_merit`
- 例：「目的別のOS選び方」→ `os_selection_by_purpose`

### insertBefore の決め方

- タイトルバナーには `insertBefore` は不要（本文への挿入なし）
- 記事中バナーはバナー内容に最も関連するH2/H3見出しの行全体を指定する
- 例：`## ベンダーロックインのリスク`、`### 未経験からベンダー系企業に就職する方法`

---

## ステップ5：Markdownファイルに画像パスを挿入する

**タイトルバナーは本文への挿入不要。記事中バナーのみ挿入する。**

記事ファイル（`./articles/{記事No}/{記事No}_index_revised.md`）の `insertBefore` で指定した見出しの直前に以下を挿入する。

```markdown
![{listTitle}](./{frameName}.webp)

```

### 挿入例

```markdown
![ベンダーロックインのリスク](./images/vendor_lock_in_risks.webp)

### ベンダーロックインとは何か
```

---

## ステップ6：ローカルサーバーを起動する

JSONが組み上がったら、以下のコマンドをバックグラウンドで実行する。

```bash
node figma-plugin/serve.js '<JSON文字列>' &
```

シングルクォートの中にJSONをそのまま埋め込む。

---

## ステップ7：Figmaプラグインを開くよう案内する

サーバー起動後、以下を案内する。

```
✅ バナーデータを配信中です（60秒間有効）

Figmaプラグイン「WMブログ バナー生成」を開いてください。
→ 開いた瞬間にバナーが自動作成されます。
```

---

## 完了時の報告

```
✅ バナー生成の準備が完了しました

- 記事No：{記事No}
- タイトルバナー：1枚（thumbnail）
- 記事中バナー：{N}枚（{frameName一覧}）
- 画像パス挿入：{N}箇所
```
